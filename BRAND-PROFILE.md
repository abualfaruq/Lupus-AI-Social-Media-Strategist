# Brand Profile

File ini adalah konteks brand yang menjadi fondasi kerja Lupus. Isinya diisi
otomatis dari form yang dilengkapi user di website saat mengunduh skill. Lupus
membaca file ini di awal setiap sesi sebagai sumber utama konteks brand.

Segala sesuatu di antara penanda START dan END di bawah adalah isi Brand Profile.
Kalau di antara penanda itu masih kosong atau masih berupa placeholder (belum ada
data brand yang nyata), berarti Brand Profile belum terisi.
